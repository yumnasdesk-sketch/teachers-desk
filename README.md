# Teacher's Desk

A responsive static website built with plain HTML, CSS and JavaScript.

## Pages
- Home / About Us
- Topics
- Topic detail pages
- Printables
- Printable full-page views
- Contact Us

## Local preview
Open `index.html` in a browser, or use VS Code Live Server.

## GitHub Pages
This project includes `.nojekyll`, so it can be published directly as static files.
